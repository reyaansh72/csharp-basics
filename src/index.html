Welcome to the Minimal MD Reader

To use this reader:

  1. Paste a link to a raw Markdown (.md) file in the top left input field. (e.g., a raw GitHub user content link).
  2. Click Load.
  3. Use the Menu icon on the top left to open the generated Table of Contents.
  4. Use the Color Picker and Moon/Sun icon on the top right to customize your reading experience!
