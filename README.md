# C# Scripting Basics for Absolute Beginners

Welcome! If you are new to programming, C# is a great language to learn. This guide is built specifically for **simple scripting**—writing straightforward scripts to automate tasks, process data, or build text applications.

---

## 1. Imports (`using`)
Before you write code, you tell C# which standard tools you need. We use `using` at the very top of a script to load these toolkits.

```csharp
using System; // Loads basic C# functionality (like printing text)
using System.IO; // Loads file management tools (like reading/writing files)
```

---

## 2. Displaying Text on Screen
To print text to the console screen, use `Console.WriteLine()`.

```csharp
Console.WriteLine("Hello! Welcome to C# scripting.");
```

---

## 3. Storing Text in Variables (`string`)
A variable is like a labelled box that holds data. A `string` holds text wrapped in double quotes.

```csharp
string username = "Alex";
Console.WriteLine(username);
```

---

## 4. Storing Numbers (`int` and `double`)
* Use `int` for whole numbers (integers).
* Use `double` for numbers with decimal points.

```csharp
int age = 20;
double price = 12.99;

Console.WriteLine(age);
Console.WriteLine(price);
```

---

## 5. Storing Yes/No Values (`bool`)
A `bool` (boolean) can only hold `true` or `false`.

```csharp
bool isLoggedIn = true;
Console.WriteLine(isLoggedIn);
```

---

## 6. Combining Text and Variables
You can easily insert variable values into text by placing a `$` symbol right before the double quotes, then putting variable names inside `{}` braces.

```csharp
string name = "Reyaansh";
int level = 5;

Console.WriteLine($"Player {name} reached level {level}!");
```

---

## 7. Getting User Input (`Console.ReadLine`)
To pause the script and ask the user to type something, use `Console.ReadLine()`.

```csharp
Console.WriteLine("Type your favorite food:");
string food = Console.ReadLine();

Console.WriteLine($"You like {food}!");
```

---

## 8. Converting Text to Numbers
When a user types input, C# sees it as text. If you want to do math with user input, you must convert it into a number using `Convert.ToInt32()`.

```csharp
Console.WriteLine("Enter your birth year:");
string input = Console.ReadLine();

int year = Convert.ToInt32(input);
int age = 2026 - year;

Console.WriteLine($"You are {age} years old.");
```

---

## 9. Making Decisions (`if` / `else`)
Use `if` statements to run code only when a condition is true.

```csharp
int userAge = 18;

if (userAge >= 18)
{
    Console.WriteLine("Access granted.");
}
else
{
    Console.WriteLine("Access denied.");
}
```

---

## 10. Checking Multiple Conditions (`else if`)
You can chain checks together if there are more than two choices.

```csharp
int score = 85;

if (score >= 90)
{
    Console.WriteLine("Grade: A");
}
else if (score >= 80)
{
    Console.WriteLine("Grade: B");
}
else
{
    Console.WriteLine("Grade: C or below");
}
```

---

## 11. Counting with For-Loops
A `for` loop repeats code a fixed number of times.

```csharp
// Starts at 1, keeps going while i <= 3, adds 1 each step (i++)
for (int i = 1; i <= 3; i++)
{
    Console.WriteLine($"Step number {i}");
}
```

---

## 12. Repeating While Something is True (`while`)
A `while` loop keeps running as long as a condition stays true.

```csharp
int counter = 3;

while (counter > 0)
{
    Console.WriteLine($"Countdown: {counter}");
    counter = counter - 1; // Decrease by 1
}

Console.WriteLine("Done!");
```

---

## 13. Storing Multiple Items (Lists)
A `List` lets you hold multiple items in one place and grow or shrink as needed.

```csharp
using System.Collections.Generic;

List<string> tasks = new List<string>();

tasks.Add("Clean room");
tasks.Add("Write code");

Console.WriteLine($"Number of tasks: {tasks.Count}");
```

---

## 14. Looping Through Every Item (`foreach`)
A `foreach` loop is the easiest way to process every item in a list one by one.

```csharp
List<string> colors = new List<string> { "Red", "Green", "Blue" };

foreach (string color in colors)
{
    Console.WriteLine($"Color: {color}");
}
```

---

## 15. Simple Script Functions (Methods)
Functions let you package useful actions so you can reuse them anywhere in your script.

```csharp
// Define the function
void PrintHeader(string title)
{
    Console.WriteLine("====================");
    Console.WriteLine(title);
    Console.WriteLine("====================");
}

// Call the function
PrintHeader("My Script Output");
```

---

## 16. Writing Text to a File
For simple scripting, saving data to a file on your computer is easy with `File.WriteAllText()`.

```csharp
using System.IO;

string content = "This is a log message generated by my script.";

// Saves the text into a file named log.txt
File.WriteAllText("log.txt", content);

Console.WriteLine("File created successfully!");
```

---

## 17. Reading Text from a File
You can read the entire content of a file into a variable using `File.ReadAllText()`.

```csharp
using System.IO;

// Reads all text inside log.txt
string fileData = File.ReadAllText("log.txt");

Console.WriteLine("File contents:");
Console.WriteLine(fileData);
```

---

## 18. Checking if a File Exists
Before reading or editing a file, check if it exists using `File.Exists()`.

```csharp
using System.IO;

if (File.Exists("log.txt"))
{
    Console.WriteLine("Log file found!");
}
else
{
    Console.WriteLine("Log file does not exist.");
}
```

---

## 19. Handling Errors (`try / catch`)
To prevent your script from crashing if something goes wrong (like a missing file or invalid user input), wrap your code in a `try / catch` block.

```csharp
try
{
    int number = Convert.ToInt32("NotANumber"); // This causes an error
}
catch (Exception ex)
{
    Console.WriteLine("An error occurred! Details: " + ex.Message);
}
```

---

Happy scripting! Focus on building small utility scripts first to practice these building blocks.
